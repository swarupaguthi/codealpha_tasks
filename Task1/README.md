# Task 1: Typography Practice

## Objective

To master the art of typography and improve visual communication through effective use of text, font styles, spacing, and layout.

## Skills Developed

* Font pairing and typography selection
* Visual hierarchy and text organization
* Spacing, alignment, and readability
* Creation of impactful text-based designs
* Understanding the psychological impact of different typefaces

## Tools Used

* Canva
* Adobe Illustrator
* Adobe Photoshop

## Outcome

Designed typography-based creative layouts that demonstrate strong visual hierarchy, balanced composition, and effective communication through text. This task helped develop a deeper understanding of how typography influences user perception and enhances design aesthetics.
